# Word Echo

A colourful word-puzzle game about homophones (words that sound alike but mean different things).
Each question is a sentence with a blank; pick the right word from two look-alike options before the timer runs out.

- **Package:** `com.lumipopgames.wordecho`
- **Company:** Lumipop Games
- **Engine:** Unity 6000.4 (portrait, Android)

## Project notes

- App identity (name, company, package, version) lives in `Assets/Scripts/Editor/AppIdentity.cs`;
  run **Tools > Homophones > Apply App Identity** after changing it.
- UI skin and layout are generated by **Tools > Homophones > Apply Colorful UI**
  (`Assets/Scripts/Editor/ColorfulUIRestyler.cs`), using the Colorful_UI sprite pack.
- Music and sound effects in `Assets/Audio/Generated/` are original, procedurally synthesized audio.
